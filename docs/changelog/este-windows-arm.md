### Este Windows em PC com processador ARM
#### Corrigido
- Num Windows com processador ARM, "Preparar este Windows" baixava o Linux de PC Intel/AMD e parava com "Exec format error". Agora baixa o certo para o processador, e quem já tinha a distro errada ganha a certa ao preparar de novo.
### Seletor: botão "Copiar erro"
#### Novo
- Quando uma máquina do seletor mostra um erro (por exemplo, ao preparar o "Este Windows" ou instalar o backend), aparece o botão "Copiar erro", que copia a mensagem, o registro do que foi feito e a versão do app para colar numa conversa de suporte.
