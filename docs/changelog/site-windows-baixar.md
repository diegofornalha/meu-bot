### Site: quem chega de Windows vai para o download da versão de teste
#### Mudado
- Na página inicial, na de agradecimento e no botão fixo, o visitante de Windows agora vê "Baixar para Windows (versão de teste)", que leva à página do instalador. Antes só havia o pedido de contato para ser avisado; ele continua lá, como segunda opção, para quem quer a versão que roda no próprio computador.
- As perguntas frequentes e a página de download do Mac passam a dizer que existe a versão de teste para Windows e o que ela faz.
