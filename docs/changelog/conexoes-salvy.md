### Conexões: Salvy no Claude Code com um clique
#### Novo
- Configurações › Conexões lista serviços que o seu Claude Code pode usar. O primeiro é o Salvy: linhas, faturas, centros de custo e equipamentos da telefonia da empresa. O botão Conectar registra o Salvy no Claude Code deste Mac. Depois, no Claude Code, rode /mcp e entre com a conta do painel do Salvy. O app não vê a sua senha.
