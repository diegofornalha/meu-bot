Versão de teste para Windows (cliente de VPS)

Esta é a versão de teste do meu-bot para Windows 10 e 11 de 64 bits. No Windows o app é o cliente de uma máquina remota (uma VPS, por exemplo): ele conecta por SSH e você conversa com o agente que roda lá.

O que ela não faz: não roda o agente no seu próprio computador e não tem o Navegador, o Gmail nem o painel Computador do app do Mac. Se você quer instalar e usar no próprio computador, hoje isso existe só no Mac.

Baixar para Windows

Do que você precisa

  • Windows 10 ou 11 de 64 bits. Em computadores com chip ARM (Snapdragon) o app roda por emulação.
  • Uma máquina remota com o meu-bot instalado e o acesso por SSH configurado no arquivo .ssh\config da sua pasta de usuário. O cliente SSH já vem no Windows.

Como instalar

  1. Abra o arquivo baixado. O instalador ainda não tem assinatura da Microsoft. Por isso o Windows mostra o aviso "O Windows protegeu o computador", com "Editor desconhecido". Clique em Mais informações e depois em Executar assim mesmo. O app é feito pela Coflow e o código é aberto.
  2. Espere a instalação. Ela é só para a sua conta do Windows e não pede senha de administrador. O meu-bot-staging abre sozinho no fim.
  3. Escolha a máquina. O app lista as máquinas do seu .ssh\config; escolha uma e entre com a sua conta.

O que ainda não tem no Windows

  • Rodar o agente no próprio computador: no Windows o app é só o cliente de uma máquina remota.
  • O agente usando o Navegador e o Gmail do app, os atalhos na área de trabalho e o painel Computador.

Atualizações

O app baixa a versão nova sozinho, confere a assinatura do meu-bot e pede para reiniciar. Todas as versões ficam no GitHub.
